# #Embedded — умный фотоальбом

Веб-приложение для просмотра фотографий с автоматическим сканированием папок,
превью (WebP) и ручными описаниями к снимкам.

## Быстрый старт

### 1. Скачайте архив проекта
Скачайте архив с репозиторием и распакуйте его в удобную папку на компьютере.
В корне распакованного архива должны быть файлы `app.py`, `config.py`,
`requirements.txt` и папки `ui/`, `db/`, `services/`.

### 2. Настройте окружение
Рекомендуется использовать изолированное виртуальное окружение, чтобы не
ломать системные пакеты Python.

```bash
# Перейдите в папку проекта
cd smart-album

# Создайте виртуальное окружение
python -m venv .venv

# Активируйте его
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Windows (cmd):
.venv\Scripts\activate.bat
# macOS / Linux:
source .venv/bin/activate

# Установите зависимости
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Укажите папку с фото в `config.py`
Откройте файл `config.py` и укажите путь к папке с вашими фотографиями.
По умолчанию используетсяrelative-путь `./photos` (папка `photos` рядом с
проектом), но вы можете задать абсолютный путь к любой папке:

```python
# config.py
import os
from pathlib import Path

# Пример для Windows:
PHOTOS_DIR = Path(os.getenv("PHOTOS_DIR", r"C:\Users\ВашеИмя\Photos")).resolve()

# Пример для macOS / Linux:
# PHOTOS_DIR = Path(os.getenv("PHOTOS_DIR", "/Users/ваш_имя/Photos")).resolve()
```

Либо не редактируя код, задайте переменную окружения `PHOTOS_DIR` перед запуском
(она имеет приоритет над значением по умолчанию).

Остальные параметры (`DB_PATH`, `CACHE_DIR`, `HOST`, `PORT` и др.) можно оставить
без изменений или подстроить под себя в том же файле `config.py`.

### 4. Запустите приложение
```bash
# Запуск веб-сервера
python app.py
```

По умолчанию приложение будет доступно по адресу:
http://localhost:8000

Откройте эту ссылку в браузере. После первого запуска нажмите в интерфейсе
кнопку сканирования (или перезапустите приложение), чтобы фото из указанной
папки попали в базу данных и отобразились в альбоме.

## Полезные переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `PHOTOS_DIR` | Папка с фотографиями | `./photos` |
| `DB_PATH` | Путь к файлу базы данных | `./album.db` |
| `CACHE_DIR` | Папка кэша превью | `./cache` |
| `HOST` | Хост сервера | `0.0.0.0` |
| `PORT` | Порт сервера | `8000` |

Пример запуска с переменными окружения (Windows PowerShell):
```powershell
$env:PHOTOS_DIR = "D:\Фото"
$env:PORT = "8000"
python app.py
```
